01 / Overview

About ImmunoPredict

ImmunoPredict is an educational machine learning replication project inspired by the LORIS framework. It explores how biological and clinical variables can be used to investigate patterns in immunotherapy treatment outcomes.

The challenge

Patients can respond differently to immune checkpoint blockade. Understanding factors associated with these differences is an important area of cancer research.

The approach

A logistic regression model is trained using the Chowell dataset, incorporating clinical, biological and cancer-type variables.

The objective

To reproduce a selected machine learning workflow and demonstrate how research data can be explored through an interactive prototype.

02 / Research

The science behind the project

Immunotherapy uses the immune system to help recognise and attack cancer. Immune checkpoint blockade treatments target pathways that can otherwise limit immune activity.

Immune checkpoint blockade

Treatments targeting immune checkpoints such as PD-1, PD-L1 and CTLA-4 have changed the treatment landscape for several cancers.

Biomarkers

Variables such as tumour mutational burden, albumin and neutrophil-to-lymphocyte ratio are investigated as possible indicators associated with outcomes.

Machine learning

Machine learning provides methods for examining relationships across multiple variables and evaluating classification performance.

03 / Evaluation

Model performance

The selected logistic regression model was evaluated on a held-out test dataset.

69.7% Test accuracy
0.760 ROC-AUC
42.7% Precision
66.9% Recall
Interpreting the results: Test accuracy was below the 75.3% majority-class baseline. The ROC-AUC indicates some ability to distinguish between the two outcome classes, but these results do not establish clinical usefulness.
04 / Methodology

How it was built

01. Data

Publicly available Chowell training and test datasets were used for the replication workflow.

02. Training

The selected classification model was logistic regression, trained to distinguish response and non-response labels.

03. Application

The trained model was integrated into a Gradio prototype to demonstrate its inputs and outputs.

Limitations

  • The model reflects the patients and treatments represented in the dataset.
  • It has not been independently clinically validated.
  • Its predictions may not generalise to other populations or settings.
  • Model probabilities are not guarantees of individual outcomes.
ImmunoPredict is an educational research prototype. It is not intended for diagnosis, treatment selection or individual medical advice.
